An .animpack holds every clip for one character, beside its MASTER folder. The Wii loader is 0x800f26f0 (loadCharacter.cpp). Tracks name bones by index into the character's skeleton.

Track (0x10 bytes)

OffsetSizeTypeDescription
0x004u32Key count
0x044offKeys
0x081u8Bone index
0x091u8Channels: 0x1 rotation, 0x2 translation, 0x4 scale
0x0A6u8[6]0

A channel the track lacks keeps the skeleton's rest value (0x800c8f50).

Keys

Each key is the time, then the rotation, three translation components and three scale components, with only the track's channels present. Each track's keys are padded to 4 bytes with 0xFE. The packed rotation is a u32 in the platform's byte order; times, translations and scales are assembled low byte first on every platform.

  • Time (0x800c6dc0): range * v / (2^(8n) - 1), clamped to the range, where n is the time byte count and the range is the field at 0x48. With the files' 8.5 and one byte, a key byte is a frame number at 30 fps.
  • Rotation (0x800c6bb0): the top two bits name the largest component, which is rebuilt from the other three. Those are 10-bit fields, high bits first, each (c - 0.5) * step - max with max = sqrt(0.5) and step = 2 * max / 1023. The quaternion is normalised afterwards.
  • Translation (0x800c6f60): sign-magnitude. The low bits over their maximum, v / (2^(8n-1) - 1) in single precision, times 100 * range from 0x40, negated when the top bit is set. The result is in centimetres.
  • Scale (0x800c7430): the same, times the range at 0x44 without the 100.

Sampling

The key search (0x800c9360) finds the keys either side of the time and interpolates with u = (t - t0) / (t1 - t0). After the last key the segment runs to the duration at 0x34: back to the first key when the clip loops, holding the last one otherwise.

  • Translations and scales interpolate as a + u * (b - a), fused.
  • Rotations slerp (0x80091210). The first quaternion is negated when the dot product is negative, and when the two are within 1e-4 of each other the blend falls back to linear weights. Neither path renormalises.

Curves (0x10 bytes)

Animated model parameters, matched against the .gds parameter table: u32 key count, off keys, u32 target name hash at 0x08, u8 target sub-index at 0x0C, runtime target index at 0x0D (set by 0x800f26f0), two zero bytes. A key is a time and a sign-magnitude value times the range at 0x4C. No file uses curves.

In OmegaStudio

  • Every key time, rotation, translation and scale in six packs, 1,748,046 values in all, decodes bit-identically to the game's four decoders.
  • The reader rejects non-zero data in the LOD 1-5 track slots, the curve fields or a track's reserved bytes, and unknown channel bits.
  • Clips play on the character's master model at 30 fps. Before the first key and after the last, the Viewport holds the end key rather than wrapping.
  • Packs export and import as JSON, with clip names restored from their hashes where known. The writer re-encodes each rotation as the packed value that decodes closest to it and picks the translation steps the game decodes back to the same float, so unchanged keys rebuild byte for byte.

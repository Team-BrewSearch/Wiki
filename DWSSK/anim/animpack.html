.animpack holds one pack per character, beside its MASTER folder. Loader: 0x800f26f0 (loadCharacter.cpp). Each pack contains multiple clips. A clip's skeleton LOD in use picks the track table.

Tracks (0x10 bytes)

OffsetSizeTypeDescription
0x004u32Key count
0x044offKeys
0x081u8Bone index
0x091u8Channels: 0x1 rotation, 0x2 translation, 0x4 scale
0x0A6u8[6]0

A channel the track lacks keeps the skeleton's rest value (0x800c8f50).

Keys

Each key is packed as: the time; the rotation; three translation components; three scale components; with only the track's channels present. The stride is the time bytes plus 4 (or 16) plus 3 × translation bytes plus 3 × scale bytes. Each track's keys are padded to 4 bytes with 0xFE. The packed rotation is a u32 in the platform's byte order; times, translations and scales are assembled from their bytes low byte first on every platform.

  • Time (0x800c6dc0): range × v / (2^(8n) − 1), clamped to the range, where n is the time byte count and range is the field at 0x48. With the files' 8.5 and one byte, a key byte is a frame number at 30 frames per second.
  • Rotation (0x800c6bb0): the top two bits name the largest component, which is rebuilt; the other three are 10-bit fields, high bits first, each (c − 0.5) × step − max with max = √0.5 and step = 2 × max / 1023. The quaternion is normalized afterwards.
  • Translation (0x800c6f60): sign-magnitude. The low bits over their maximum, v / (2^(8n−1) − 1) in single precision, times 100 × range (0x40), negated when the top bit is set: a value in centimetres.
  • Scale (0x800c7430): the same, times the range at 0x44 without the 100.

Sampling

The key search (0x800c9360) finds the pair of keys around the time and interpolates with u = (t − t0) / (t1 − t0). After the last key the segment runs to the duration (0x34): back to the first key when the clip loops, holding the last otherwise. Translations and scales interpolate as a + u × (b − a). Rotations use a slerp when the dot product is negative (negate the first quaternion), blend linearly when within 1e-4 of each other, and otherwise slerp. Neither path renormalizes.

Curves (0x10 bytes)

Animated model parameters, matched against the .gds parameter table: u32 key count, off keys, u32 target name hash at 0x08, u8 target sub-index at 0x0C, runtime target index at 0x0D (set at load by 0x800f26f0), two zero bytes. A key is a time followed by a sign-magnitude value times the range at 0x4C. No file uses curves.

Verified: Every key time, rotation, translation and scale in six .animpack files, 1,748,046 values in all, decoded bit-identically to the game's decoders (0x800c6dc0, 0x800c6bb0, 0x800c6f60, 0x800c7430).

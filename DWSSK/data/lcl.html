Localised text. One string table per language. Lookup: 0x800f5370.

File Layout

OffsetSizeTypeDescription
0x004u32String count
0x04-records0x10 bytes each

Record (0x10 bytes)

OffsetSizeTypeDescription
0x004u32Hash
0x044offOffset of the string from the start of the file
0x084u320
0x0C4u32A value that is the same for every record in a file

The lookup only reads the first two words. It is a binary search that expects the hashes in descending order; a hash it can't find returns an empty string. Strings are NUL-terminated UTF-8, and identical strings share one copy.

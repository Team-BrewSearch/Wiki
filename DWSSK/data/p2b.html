.p2b (usually .tuning.p2b) is a self-describing tuning table: it carries the type definitions, enums and strings needed to read its own objects. The Wii loader is 0x800925a0, and each object is registered with 0x80093270.

Header

OffsetSizeTypeDescription
0x002u16Version, 0x000A; its byte order gives the file's
0x022u16Flags: bit 0 relocated, bit 1 ready; a table with bit 0 set is not relocated again
0x048u32, offTypes: count, then 0x0C-byte entries
0x0C8u32, offObjects: count, then 8-byte entries
0x148u32, offEnums: count, then 0x0C-byte entries
0x1C8u32, offStrings: count, then 8-byte entries

Tables

TableEntry
Typesu32 type name hash, u32 field count, off field records
Objectsoff descriptor record, off data
Enumsu32 enum name hash, u32 value count, off values ({u32 name hash, i32 value} each)
Stringsu32 hash, off NUL-terminated string

The string table names everything else: types, fields, enum values and hashed values all resolve through it.

Field Record (16 bytes)

OffsetSizeTypeDescription
0x001u8Kind (below)
0x013-Unknown, copied through
0x044u32Type hash: the struct or enum the field uses
0x084u32Field name hash
0x0C4u32Offset of the field inside its struct

A pointer or array record is followed directly by the record describing what it points to.

A struct is as large as its furthest field, rounded up to its alignment, which is that of its most aligned field. Strings are hashed by one of four schemes: plain CRC-32, CRC-32 of the upper-cased name, the path hash, or the Wwise FNV-1.

In OmegaStudio

  • Tables export and import as JSON: the types, enums and strings, then every object decoded field by field through its own descriptors, with hashes turned back into names. A pointer to another object becomes a reference to it by name.
  • Floats that are not finite keep their exact bits, and an unknown hash stays as # plus its hex value.
  • Writing hashes a new name with the scheme its field kind calls for and rebuilds every table and offset.

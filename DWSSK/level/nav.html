Navigation.nav in each level holds the AI's navigation meshes. The Wii loader is 0x800952e0 (NavMesh.cpp).

Layout

OffsetSizeTypeDescription
0x004char[4]Magic Nav\0
0x044u32Version, 11
0x084u32Mesh count
0x0C0x28 * nmesh[]Meshes

Mesh (0x28 bytes)

OffsetSizeTypeDescription
0x004u32Vertex count
0x044u32Polygon count
0x084u32Edge count
0x0C24f32[6]Bounding box: minimum, maximum
0x244offData: vertices (f32 x 3), then polygons, then edges (u16 x 2)

The loader records the three arrays per mesh and builds a lookup over the polygons.

Polygon (0x14 bytes)

OffsetSizeTypeDescription
0x006u16[3]Vertex indices
0x062u16Unused
0x084u32First edge
0x0C4u32Edge count
0x104u32Flags

In OmegaStudio

  • Byte order is detected from the version word. The meshes show in the Viewport and export as OBJ, one object per mesh.
  • The file exports and imports as JSON. Writing packs each mesh's vertices, polygons and edges back to back after the mesh table.

.htx is the texture format on all four platforms: a small header of eight words, then pixel data in the platform's own layout. Models name textures by the path hash of their .htx entry.

Header

OffsetSizeTypeDescription
0x004u32Magic 0xFC000001, in the platform's byte order
0x044u32Width
0x084u32Height
0x0C4u32Unknown
0x104u32Mipmap level count
0x144u32Format (below)
0x184u32Flags: bit 0 set means swizzled (PS3)
0x1C4offPixel data

A file whose first byte is 0xFC is big-endian. On Xbox 360 the WAD puts offset 0x80 of each texture on a 4 KB boundary, so pixel data stored there is page-aligned.

16-bit texels are big-endian. Levels follow one another, largest first, each half the size of the last (never below 1).

Platform Layouts

PS3

Uncompressed levels are linear rows, or Morton-swizzled when flag bit 0 is set. DXT levels are standard BCn blocks.

Xbox 360

Each level is stored in rows of blocks (1x1 for uncompressed formats, 4x4 for DXT) with a pitch of max(256, align(blocks wide, 32) * block bytes). A level's height is padded to a multiple of 32 block rows, except in a single-level texture shorter than 32 pixels. DXT blocks are stored as byte-swapped 16-bit words.

Wii

  • RGBA8 uses GX tiles of 4x4 texels, 64 bytes each: 16 A, R pairs, then 16 G, B pairs.
  • LA8 uses 4x4 tiles of A, L byte pairs.
  • DXT1 is GX CMPR, with sizes rounded up to 8 texels. Other sizes round up to 4.

3DS

Format 8 wraps a single-texture CTPK container holding a PICA200 texture: RGBA8, RGB8, RGBA5551, RGB565, RGBA4444, LA8, HILO8, L8, A8, LA4, L4, A4, ETC1 or ETC1A4. The CTPK carries the real size and mipmap count.

In OmegaStudio

  • Every platform layout decodes; formats and channel orders follow the tables in the game executables.
  • Replacing from a PNG keeps the size and format and rebuilds every mipmap level. A PNG identical to the current image keeps the original bytes, and the lossless formats give back the same bytes for an unchanged image.
  • A model's texture is looked up in its own WAD, then its other parts, then global.wad, then the rest of the game folder.

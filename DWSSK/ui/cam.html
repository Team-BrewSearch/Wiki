.cam camera path files. The loader has not been found, so this layout comes from the files only. Every file round-trips through the plugin.

File Layout

OffsetSizeTypeDescription
0x004u32Version
0x044off, u32Position keys, 4 × f32 each
0x0C4off, u32Direction keys, 4 × f32 each
0x144off, u32Field-of-view keys, 2 × f32 each
0x1C-Key data, in that order

The last float of each key is its time.

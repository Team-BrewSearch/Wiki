.cam files are camera paths. Their loader has not been found, so this layout comes from the files alone.

Layout

OffsetSizeTypeDescription
0x004u32Version
0x048off, u32Position keys and their count, 4 x f32 each
0x0C8off, u32Direction keys and their count, 4 x f32 each
0x148off, u32Field-of-view keys and their count, 2 x f32 each
0x1Cvarf32[]Key data, in that order

The last float of each key is its time.

In OmegaStudio

  • Byte order is detected from the first offset, which is always 0x1C. Every file round-trips through the plugin.
  • The file exports and imports as JSON; writing packs the three key arrays back to back from 0x1C.

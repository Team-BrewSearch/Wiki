.fkd is font kerning data: glyph cells and advances for a font texture. The Wii loader is 0x80ee9c0.

0x388 * nglyph[]Glyphs

The loader rejects a font whose bytes 0x04-0x06 or 0x0D are wrong, and keeps a pointer to the glyphs at 0x38.

Glyph (8 bytes)

One per character code, in range order: u16 x, u16 y, u16 advance, u16 height.

In OmegaStudio

  • Byte order is taken from the first metric. The glyph table must be a whole number of 8-byte glyphs and no longer than the ranges cover; each glyph is labelled with its character.
  • The file exports and imports as JSON. Bytes 0x04-0x0F are carried through as they are.

DSARCFL

DSARC FL archive format specification

archive DSARC FL is a container format used to bundle multiple audio, music, and sound effect files into a single .dat archive.

  • Magic: ASCII "DSARC FL" (8 bytes)
  • Version: 32-bit unsigned integer (little-endian)
  • Entry Count: 32-bit unsigned integer (little-endian)
  • Header Size: 16 bytes (magic + count + version)
  • Name Field Size: 40 bytes per entry (UTF-8, null-padded)
  • Entry Info Size: 8 bytes per entry (size + offset)

File Layout

+----------------------+   <-- offset 0
| Magic (8 bytes)      |       "DSARC FL"
+----------------------+   <-- offset 8
| Count (4 bytes)      |       Number of entries (uint32 LE)
+----------------------+   <-- offset 12
| Version (4 bytes)    |       Format version (uint32 LE)
+----------------------+   <-- offset 16 (HEADER_SIZE)
| Entry Table ...      |       count * (40 + 8) bytes
+----------------------+   <-- data start
| File Data Section... |
+----------------------+   <-- EOF

Header

OffsetLengthTypeDescription
0x008char[8]Magic identifier "DSARC FL"
0x084u32Number of entries (little-endian)
0x0C4u32Archive version (little-endian), currently 1

Entry Table

Each entry consists of a 40-byte name, followed by 8 bytes of metadata.

FieldLengthTypeDescription
Name40char[40]Null-padded UTF-8 relative file path
File Size4u32Data length in bytes
Data Offset4u32Byte offset to file data (from start of archive)

Data Section

File data is concatenated immediately after the entry table, in the same order as table entries.

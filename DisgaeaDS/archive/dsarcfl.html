DSARC FL bundles named files into one .dat archive. Disgaea DS uses it for all its audio: bgm.dat, song.dat, se.dat, voice.dat and msgvo.dat, each with a .tbl beside it.

Layout

+----------------------+   <-- 0x00
| Header               |       16 bytes
+----------------------+   <-- 0x10
| Entry table          |       count * 48 bytes
+----------------------+
| File data            |       in table order
+----------------------+   <-- EOF

Header

OffsetSizeTypeDescription
0x008char[8]Magic "DSARC FL"
0x084u32Entry count
0x0C4u32Version, 1

Entry (48 bytes)

OffsetSizeTypeDescription
0x0040char[40]Relative file path, NUL-padded
0x284u32File size
0x2C4u32Data offset, from the start of the archive

All integers are little-endian. File data follows the entry table directly, in table order.

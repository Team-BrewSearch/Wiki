DSEQ

Music archive format (.msnd)

music DSEQ is a custom archive that bundles Nintendo DS music data into a single .msnd file. It contains exactly three sequential binary chunks:

  • SSEQ - sequence data
  • SBNK - sound bank
  • SWAR - wave archive

File Structure

OffsetSizeTypeDescription
0x004char[4]Magic "DSEQ"
0x0412uint8[12]Reserved (always zero)
0x104uint32SSEQ offset + 0x10
0x144uint32SBNK offset
0x184uint32SWAR offset
0x1C4uint32Reserved (zero)
0x204uint32SSEQ size
0x244uint32SBNK size
0x284uint32SWAR size
0x2C4uint32Unknown
Note: SSEQ offset + 0x10 is stored at 0x10 - subtract 0x10 to get the actual SSEQ start. All offsets are relative to the beginning of the file.

Chunk Order

The order is fixed: SSEQ → SBNK → SWAR. Each chunk is placed immediately after the previous one. The SWAR size is a 64-bit value split into two 32-bit little-endian values.

Reference for the file formats used in Suzumiya Haruhi no Chourantou (also updated and most known as Suzumiya Haruhi no Gekitou), a Direct3D 9 title for Windows. Everything here was reverse engineered from the retail 2007 data files.

File Formats

    Conventions

    These hold across every format on this wiki unless a page says otherwise.

    Byte order
    Little-endian for all integers
    Floats
    IEEE-754 binary32
    Strings
    Fixed-width, null padded, not null terminated
    Matrices
    Row-vector Direct3D convention (v' = v * M), translation in the last row
    Coordinates
    Left-handed, Y up, roughly 1 unit per centimetre
    Padding byte
    0xFE inside archive tables, 0x00 elsewhere

    Geometry, bind matrices and animation keys all share that one space. Converting to a right-handed target is a mirror rather than a rotation: negate one axis, conjugate every matrix by it, and reverse triangle winding.

    Data Layout

    All shipped assets live under data/. Every .bin there is the same nested table of contents; the payloads below are what the leaves turn out to be.

    data/ ├── *.bin [BIN] - character and stage archives │ ├── (model blob) - node graph, meshes, embedded ringtex2 textures │ ├── (animation blobs) - one clip each, siblings of the model blob ├── bgm.bin [BIN] │ └── (Ogg Vorbis) - background music ├── se.bin [BIN] │ └── (RIFF WAVE) - sound effects ├── voice.bin [BIN] │ └── (RIFF WAVE) - voice clips ├── eff.bin [BIN] │ └── (BTEF) (29 blobs) - effect scripts, not reverse-engineered ├── param.bin - gameplay tables, not reverse-engineered ├── sce.bin - not reverse-engineered ├── sys.bin - not reverse-engineered └── sel.cdt - UI data, not reverse-engineered

    Archive leaves carry no filenames, so payloads are identified by magic bytes and structure. Names in parentheses above are descriptive, not stored.

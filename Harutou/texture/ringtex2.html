ringtex2 is a 64-byte header followed by raw RGBA8 pixels. It is the only texture format in the shipped data: no DXT, no mip chain, no palette. Textures appear both as standalone archive payloads and embedded at the end of model blobs.

Header

OffsetSizeTypeDescription
0x0016char[16]Magic "ringtex2", null padded
0x1016char[16]Asset name, null padded, e.g. hi00_body
0x2012-Unknown
0x2C4u32Width in pixels
0x304u32Height in pixels
0x3412-Unknown
0x404 * w * hu8[]Pixels, RGBA8, top-down, no row padding

There is no length field. A texture is exactly 0x40 + 4 * w * h bytes, so a 128x128 texture is 0x10040 bytes.

Channel Order

Pixels are stored R, G, B, A, not the B, G, R, A a Direct3D 9 A8R8G8B8 surface would hold in memory. Across the 140 face textures the channel means are 220, 163 and 111, a skin tone. Read as B, G, R the same bytes would average to a saturated sky blue. Alpha is 255 in every shipped texture.

In OmegaStudio

  • A blob is a texture when it is at least 0x40 bytes and starts with the 8 bytes ringtex2.
  • Width and height must each be 1 to 16384, the pixel count at most 256 Mi, and the blob must hold 0x40 + 4 * w * h bytes.
  • Pixels go to the Texture pane as they are, with no channel swap.
  • Replacing from a PNG keeps the original header, rewrites only the name and size fields, and accepts a new size.

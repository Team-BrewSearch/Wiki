ringtex2 is a 64-byte header followed by raw pixels. It is the only texture format in the shipped data: no DXT, no mip chain, no palettised variant. Textures appear both as standalone archive payloads and embedded inside model blobs.

Header

OffsetSizeTypeDescription
0x0016char[16]Magic "ringtex2", null padded
0x1016char[16]Asset name, null padded, e.g. hi00_body
0x2012-Not reverse-engineered
0x2C4u32Width in pixels
0x304u32Height in pixels
0x3412-Not reverse-engineered
0x40w * h * 4u8[]Pixel data, BGRA8, top-down, no row padding

There is no length field. Total size is exactly 0x40 + w * h * 4, so a 128x128 texture is 0x10040 bytes.

Channel Order

Pixels are stored B, G, R, A. Across the 140 face textures the per-channel means are 220 / 163 / 111, a skin tone; read as R, G, B, A the same bytes would average to a saturated sky blue. Alpha is 255 in every shipped texture.

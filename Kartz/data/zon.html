A .zon is a bundle of scenery models. Each model is one chunk in exactly the format a TRK chunk uses, so scenery draws, exports and re-imports through the same path a track does.

Layout

OffsetSizeTypeDescription
0x004u32Model count
0x044u32Header size: 12, or 16 in the later games
0x084u32File size minus the header size
0x0C4u32Spare zero word, 16-byte header only
header4 * countu32[]Absolute offset of each model's chunk
varvarchunk[]Model chunks, in table order
var12 * count-Trailer, 12 bytes per model, unknown

The trailer starts at the end of the last chunk, not at a stored offset. It is always 12 bytes per model: models/garage/garage.zon carries 156 bytes for its thirteen models, and all 116 Kartz bundles follow the rule. Later games can leave gaps between chunks.

Positions stay inside the ±8 range a VTX_16 can hold, so models are authored small and placed by the code that loads them. Texture coordinates are in texels and divide by the bound texture's size; every Kartz bundle resolves a texture, and all but the tiled water planes stay within a span of eight.

Textures

A chunk names its texture by slot, resolved through the resource databases exactly as a track's is (see texture binding). Skyboxes are named together: one record lists every skybox model and a texture table of the same length, and model i takes texture i. 119 Kartz models are paired that way, and every pairing agrees with the file names, from SKY_ToothlessCove.zon and SKY_ToothlessCove.5tx down to mudblock.zon and mudblock.5tx.

In OmegaStudio

  • The model count is 1 to 4096, the header size is 12 or 16, a 16-byte header's spare word is zero, the size word is at least 4 and at most the file size minus 12, and the offset table fits.
  • Every model offset lands after the table and holds a narrow or wide chunk that fits the file.
  • Replacing from glTF puts a node or mesh named chunk_<n> into model n, and anything unnamed into the first model. A wide chunk keeps its original header and references. Chunks are packed back to back, empty ones copied byte for byte, and the trailer carried through. If the geometry comes back unchanged, the original bytes are kept.

Across all five games, all 588 .zon files read, draw and re-serialise to their original bytes. An unedited glTF round trip reproduces 576 of them byte for byte; Editing lists the rest.

String tables and text data across the five games. The older games keep strings in one LANG table; the 2011 games use FCOL tables, CSV sources and hand-written resource files.

LANG

data/lang/lang.bin in CNK2, CNK3D and Krazy Kart Racing.

OffsetSizeTypeDescription
0x004char[4]Magic "LANG"
0x044u32Language count L
0x084u32Strings per language S
0x0C4u32Encoding: 1 UTF-8, 2 UTF-16LE
0x104u32Byte length of the language name block
0x14var-Language names, NUL-terminated, in the file's encoding
var16 * L{u32 offset, u32 size, u32 packed size, u32 name offset}[L]Language records
varvar-One zlib blob per language, back to back

Each blob inflates to exactly S NUL-terminated strings, so string k means the same thing in every language.

FCOL

data/locale/bstrings.* in Raging Thunder 2.

OffsetSizeTypeDescription
0x004char[4]Magic "FCOL"
0x044u32Count N
0x088 * N{u32 key offset, u32 value offset}[N]String records
varvarchar[]Keys, ASCII, NUL-terminated, back to back
var0 or 1u80xFF when needed to reach an even offset
varvaru16[]Values, UTF-16LE, NUL-terminated, back to back

All five files (.eng, .fre, .ger, .ita, .spa) hold the same 304 keys in sorted order. Only English is translated; the rest say translate.

Getaway Locale Sources

frontend/locale/strings.b?? (bde, ben, bes, bfr, bit) are CSV files with CRLF line ends, a header row and 424 strings:

"String Identifier","Source Language Text","Target Language Translation"
"buyfull_to_enable","Kauf die vollversion, um zugang zu der strecke zu bekommen",""

Fields are not escaped: some text contains bare quotes and blank lines, so split on ",".

frontend/locale/loc_??.hxx are small hand-written resource files, also CRLF:

strings
{
	node
	{
		string id = "achievements";
		string data = "translate";
	}
	...
}

Shaders and Credits

rg/shaders.vfs holds 17 fragment (.fp) and 19 vertex (.vp) GLSL ES programs, ASCII with CRLF, such as default_vcolor, lightmap_dynlight, topdown_car, blur and game/cpy_cheapvideocam.

RT2's data/menu/credits.txt is CRLF text with light markup: lines starting with + are headings, and @1 to @3 lines place a logo.

XML

CNK2 has 27 XML files: minimap generators, a system configuration, and a 57 KB game database covering kart physics, surface materials, characters, karts, tracks, cups, missions, power-ups and unlocks. Krazy Kart Racing has one, its "Krazy Racers database" for race flow and unlocks.

In OmegaStudio

  • LANG: the encoding must be 1 or 2, fewer than 256 languages, each blob must start where the previous one ended and inflate to exactly S strings, and nothing may follow the last blob. Each language is a row whose strings are edited in the Properties pane.
  • Saving a LANG rewrites it with the name block padded to 4 bytes and each language re-compressed at level 9.
  • FCOL: every key and value must start where the previous one ended, the pad byte must be 0xFF, and nothing may follow the last value. Values are edited in the Properties pane by key.
  • CSV, HXX, shaders, credits and XML open as text rows.

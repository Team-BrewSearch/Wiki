String tables and text data across the five games. The two engine generations use different systems.

LANG (data/lang/lang.bin)

Used by CNK2, CNK3D and Krazy Kart Racing.

+0x00  4     "LANG"
+0x04  u32   language count L
+0x08  u32   strings per language S
+0x0C  u32   encoding: 1 = UTF-8, 2 = UTF-16LE
+0x10  u32   byte length of the language-name block
+0x14  ...   language names, NUL-terminated, in the file's encoding
+...   L x 16  { u32 offset, u32 uncompressed size, u32 compressed size, u32 name offset }
+...   ...   one zlib blob per language, back to back

Each blob inflates to exactly S NUL-terminated strings, so string k means the same thing in every language. CNK2: UTF-8, 5 languages (ENGLISH, FRANÇAIS, ITALIANO, DEUTSCH, ESPAÑOL), 193 strings. CNK3D: UTF-16LE, 5 languages, 315 strings. KKR: UTF-8, 6 languages (the five above plus JAPANESE), 270 strings.

FCOL (data/locale/bstrings.*)

Used by Raging Thunder 2.

+0x00  4     "FCOL"
+0x04  u32   count N
+0x08  N x 8 { u32 key offset, u32 value offset }
+...   keys: ASCII, NUL-terminated, back to back
+pad   0-1   one 0xFF byte if needed for even offset
+...   values: UTF-16LE, NUL-terminated, back to back

All five files (.eng, .fre, .ger, .ita, .spa) hold the same 304 keys in sorted order. Only English is translated; the others say translate.

Getaway Locale Sources

frontend/locale/strings.b?? (bde, ben, bes, bfr, bit) are CSV files with CRLF line ends:

"String Identifier","Source Language Text","Target Language Translation"
"buyfull_to_enable","Kauf die vollversion, um zugang zu der strecke zu bekommen",""

Each file has a header row plus 424 strings. Fields are not escaped: some text contains bare quotes and blank lines. Fields split on ",".

frontend/locale/loc_??.hxx are small hand-written resource files, also CRLF:

strings
{
	node 
	{
		string id = "achievements";
		string data = "translate";
	}
	...
}

Shaders and Credits

rg/shaders.vfs holds 17 fragment (.fp) and 19 vertex (.vp) GLSL ES programs, ASCII with CRLF. Names: default_vcolor, lightmap_dynlight, topdown_car, blur, game/cpy_cheapvideocam and others.

RT2's data/menu/credits.txt is CRLF text with simple markup: lines starting + are headings, @1 to @3 lines place a logo.

XML

CNK2 has 27 XML files: minimap generators, a system configuration, and a 57 KB game database covering kart physics, surface materials, characters, karts, tracks, cups, missions, power-ups and unlocks. KKR has one XML: its "Krazy Racers database" for race flow and unlocks.

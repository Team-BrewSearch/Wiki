PXC replaces PIFF in the 2011 games. One file holds a whole car, track or set of props as a tree of typed objects. Versions 16, 19 and 20 are Raging Thunder 2; 54 and 55 are Reckless Getaway, whose layout adds property lists and multi-block meshes.

Getaway adds one byte, 0 or 1, of unknown meaning. An animation slot chunk follows: "#RES" with size 0 for none, or a SANI chunk. Bounds are in the object's own space; the matrix and translation place it in its parent as parent = M * v + t.

Vertex Formats

Every vertex has a fixed position first and fixed texture coordinates last. Bit 0x10 adds a fixed normal after the position, and bit 0x100 a 4-byte RGBA colour after that.

Driveline curves have one to four branches, shortcuts that leave and rejoin the main line. Other curves are animation paths, AI lanes, and respawn and camera splines.

STCO Collision

Both games store track collision as triangles in a spatial hash. Material numbers 0 to 49 index the database's 50-entry material response list.

Cells

u32  node count, neighbour count, plane count, portal count
per node: u16 first neighbour, u16 neighbour count, u16 a, u16 b, u32 kind

In OmegaStudio

  • The magic, the word 1 at 0x06 and a supported version are required, and the root object must end exactly at the end of the file. Objects nest at most 64 levels deep.
  • Containers are SGGR, SGNO and SGPC in RT2, and SGGR, SGNO, SGAN and SGG2 in Getaway. Placed classes are SGNO, SGPS, SGSP, SGCA and SGME in RT2, plus SGPR, SGLI, SGMR and SGAN in Getaway (without SGME).
  • Every mesh renders in world space, placed through its parents, with one mesh per vertex block. Normals go through the inverse transpose. Vertex colours are used as baked lighting when no block has normals.
  • Vertex blocks must use one of the four formats and fit the mesh, index blocks must be GL_TRIANGLES u16 lists, and every draw range must name a real material, block and index span.
  • Curves, collision and cells are skipped, not decoded. The Properties pane counts objects by class.
  • Replacing from glTF works on scenes with MESH objects; LICM scenery cannot be replaced. A glTF mesh goes to the object of the same name, and the rest fill the remaining objects in order, surplus merged into the last. Vertices move back into each object's own space, keep the object's vertex format and materials (matched by texture name), and get fresh bounds. Each object holds up to 65,535 vertices and indices. Objects with no glTF mesh are kept.

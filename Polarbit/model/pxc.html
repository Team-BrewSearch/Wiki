PXC replaces PIFF in the 2011 games (Reckless Getaway and Raging Thunder 2). One file holds a whole car, a track, or a set of props as a tree of typed objects. Versions 16–20 are RT2; 54–55 are Getaway.

File Layout

+0x00  u32  0x1A2B3C4D
+0x04  u16  version: 16/19/20 (RT2) or 54/55 (Getaway)
+0x06  u16  1
+0x08  ...  root object, to the end of the file

Object Header

u32    class tag ("SGNO", "SGPS", ...)
u32    size of the rest of the object, to the end of its children
u16    name length L, then L bytes: name + NUL
u32    flags (0 almost everywhere; 0xC00 on some meshes, 1 on a few nodes)
       Getaway layout only: property list (below)
...    class body

Container classes hold their children. In the Getaway layout the child count is preceded by i32 -1. Most classes carry a 76-byte placement block followed by an animation slot.

Placement Block

fixed radius            bounding sphere (radius = length of half size)
fixed centre[3]         bounding box centre
fixed half size[3]      bounding box half extents
fixed matrix[9]         3x3 rotation/scale (row-major)
fixed translation[3]
[u8 0 or 1]             Getaway layout only, meaning unknown
animation slot          "#RES" + u32 0 (none) or a SANI chunk

The bounds are in the object's own space. The matrix and translation place the object in its parent: parent position = M * v + t. Mesh texture coordinates follow the v-up convention, so OBJ export uses them unchanged.

Property Lists (9.2)

u32    count
per property: u16 length + name (NUL-terminated), then a typed chunk:
  "STRI" u32 size, u16 length + string (NUL-terminated)
  "REAL" u32 4,    fixed
  "UI32" u32 4,    u32
  "bool" u32 1,    u8 0 or 1

Geometry: MESH and LICM

SGPS geometry is a MESH chunk or, for track scenery, LICM. Both start with:

fixed radius, centre[3], half size[3]    (28 bytes)
[u32 vertex block count V, u32 index block count I]     Getaway layout; RT2 has one of each
V x vertex block:  u32 format, u32 count, u32 0, vertices
I x index block:   u32 4 (GL_TRIANGLES), u32 count, u32 5, u16 indices

Vertex format bits: every vertex has a fixed position (12 bytes) and fixed texture coordinates (8 bytes); 0x10 adds a fixed normal (12 bytes) and 0x100 a 4-byte RGBA colour. Formats: 0x1000 (20 bytes), 0x1010 (32), 0x1100 (24), 0x1110 (36).

Curves

u32  point count N, fixed point[N][3]
u32  branch count
per branch: u32 point count, fixed point[][3], fixed fork distance, fixed join distance

Driveline curves have one to four branches (shortcuts) that leave and rejoin the main line. Other curves are animation paths, AI lanes, respawn and camera splines.

STCO Collision

Both games store track collision as triangles in a spatial hash. Material numbers 0-49 index the database's 50-entry material-response list.

RT2 STCO

u32  bucket count NB, u32 triangle count NT, u32 reference count NR, u32 slot count S (797)
u32  bucket count per slot [S]          (sums to NB)
NB x { u32 cell key, u32 first reference, u32 ground count, u32 wall count }
NT x 64-byte triangle:
     u32 type (1 or 2), fixed vertex[3][3], fixed plane normal[3], fixed plane d,
     3 colour bytes + 0xFF, u32 surface (low bits 0..15, bit 31 a flag)
u32  triangle index [NR]

Getaway STCO

u32  bucket count NB, u32 reference count NR, u32 slot count S (16000)
u32  bits x, u32 bits y, u32 bits z     (such as 11, 7, 14; sum to 32)
fixed cell size[3], 3 x u32 unknown
u32  bucket count per slot [S]
NB x { cell key, first reference, ground count, wall count }   (key mod 16000 = slot)
"PATA" u32 size:
  u32  triangle count NT
  NT x 80-byte triangle:
       u32 type (1, 2 or 6), fixed vertex[3][3], i32 neighbour[3] (-1 = open edge),
       fixed plane normal[3], fixed plane d, 2 x u32 unknown, u32 flags (0x40000001 on type 1)
u32  triangle index [NR]
fixed bounds[6]

Cells

SGPC (RT2 track root)

u32  node count, u32 neighbour count, u32 plane count, u32 portal count
per node: u16 first neighbour, u16 neighbour count, u16 a, u16 b, u32 kind
u16    neighbour node [neighbour count]
fixed  plane[4] per plane (unit normal, d)
fixed  quad[4][3] per portal

Nodes alternate between portals (kind 0x1000: a=1, b = portal number) and convex cells (kind 0x800: a planes starting at plane b).

SGG2 (Getaway track root)

fixed min[3], max[3], origin[3]
u32  nx, u32 nz, u32 1191, u32 1191, u32 cell count (= nx * nz)
per cell: u32 0x100 if the cell has geometry, else 0; fixed box[6]
u32  cell order [cell count]

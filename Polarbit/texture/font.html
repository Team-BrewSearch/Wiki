PFNT is Polarbit's bitmap font: one atlas per file, a glyph record for every character it covers, and pixel data in one of four encodings chosen by a format byte and a flags byte.

Header

OffsetSizeTypeDescription
0x004char[4]Magic "PFNT"
0x042u1612, the size of the fixed header that follows
0x061u80 in every font
0x071u8Widest glyph, pixels
0x081u8Ascent (baseline), smaller than the height
0x091u8Line height, equal to the atlas height
0x0A2u160 in every font
0x0C2u16First character code
0x0E2u16Last character code
0x102u16Glyph count G
0x122 * Gu16[G]Character codes, UCS-2
var4 * G{u16 x, u8 0, u8 width}[G]Glyph records

Glyphs sit side by side in one horizontal strip: glyph i spans x to x + width at full height.

Encodings

FontsFormat, flagsPalettePixel meaning
CNK2 (9), Krazy Kart Racing (5)8; 0x00 or 0x82NoneRGBA8888, bytes R, G, B, A
CNK3D, RT23; 0x38 or 0x78NoneCoverage: white at alpha = byte
CNK3D, RT23; 0x18 (RT2) or 0x58256 entriesPalette index; index 0 is transparent
CNK3D3; 0xDE35 entries3-bit alpha over a 5-bit index: alpha = v >> 5, index = v & 31, like a DS A3I5 texture

In the 0xDE font every byte is either below 35 or 224 and up, which is what suggests the A3I5 reading. It rests on that one sample.

In OmegaStudio

  • The header size word must be 12, the format 3 or 8, and the word after the atlas height 0. The pixels must fill the file exactly, and every glyph must lie inside the atlas width.
  • The atlas shows in the Texture pane, decoded by the table above; 0xDE alpha is scaled as (v >> 5) * 255 / 7.
  • Replacing from a PNG keeps the atlas size, since the glyph records point into it. RGBA8888 fonts take any colours; coverage fonts take the PNG's alpha. Palette fonts accept only the palette's own colours, plus fully transparent pixels, and refuse any other colour.

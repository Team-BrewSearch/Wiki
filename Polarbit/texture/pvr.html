All five games use PowerVR legacy (version 2) PVR textures with a 52-byte header. CNK2, CNK3D and Krazy Kart Racing also use plain PNG for 2D UI and menus.

PNG

Ordinary PNG files with valid CRCs and nothing after IEND. None use Apple's CgBI variant.

The masks show that 0x10 and 0x11 keep alpha in the low bits.

Data

Pixel data runs from offset 52 to the end of the file and holds the whole mipmap chain, largest level first, each level half the size of the one before (never below 1). PVRTC blocks are stored in PowerVR's Morton order with the y bit lowest.

Flags

BitMeaning
0x100Has mipmaps
0x200Twiddled
0x8000Has alpha
0x10000Stored bottom-up

CNK2 sets 0x8000 and 0x10000 on every file and never sets 0x100 or 0x200, even on mipmapped and PVRTC textures. Getaway and RT2 set 0x100 exactly when there are mipmaps, and 0x200 on PVRTC files. PVRTC files carry zero colour masks, and an alpha mask of 1 when they have alpha.

In OmegaStudio

  • A payload is a PVR when it starts with the word 52 and has "PVR!" at 0x2C. The surface count must be 1, the format one of the codes above, each side 1 to 16384, the mipmap count below 16, and uncompressed bits per pixel 8, 16 or 32.
  • The mipmap chain must fill the file exactly. Bottom-up textures are flipped on read and write. Twiddled uncompressed textures are not supported.
  • Uncompressed formats decode through the stored masks; a channel with a zero mask reads as 0, or 255 for alpha. PVRTC decodes in software, punch-through alpha included.
  • Replacing from a PNG with unchanged pixels keeps the original bytes. Otherwise the image is encoded in the same format, any size for uncompressed formats and powers of two for PVRTC. A resized texture with mipmaps gets a full new chain, box-filtered, and an updated header. I8 and AI88 store luminance.
  • PNG textures are decoded and replaced by the host's own codec.

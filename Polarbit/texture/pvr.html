PowerVR legacy (version 2) texture files with a 52-byte header. PVR is used by all five games; PNG is used only by CNK2, CNK3D and Krazy Kart Racing for 2D UI and menus.

PNG

Ordinary PNG files with valid CRCs and nothing after IEND. None use Apple's CgBI variant.

The masks show that 0x10 and 0x11 keep alpha in the low bits.

Data Layout

Data runs from offset 52 to the end and holds the full mipmap chain, largest level first. PVRTC blocks are stored in PowerVR's Morton order with the y bit lowest. Pixel data follows the format and padded dimensions.

Flag Bits

BitMeaning
0x100Has mipmaps
0x200Twiddled
0x8000Has alpha
0x10000Stored bottom-up

CNK2 sets 0x8000 and 0x10000 on every file and never sets 0x100 or 0x200, even on mipmapped and PVRTC textures. Getaway and RT2 set 0x100 exactly when there are mipmaps and 0x200 on PVRTC files. PVRTC files carry zero colour masks and an alpha mask of 1 when they have alpha.

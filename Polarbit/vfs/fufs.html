A .vfs archive is a FUFS container: a table of entries sorted by name hash, pointing into one contiguous payload region. Entries carry no type; a payload's format is read from its first bytes.

Layout

OffsetSizeTypeDescription
0x004char[4]Magic "FUFS"
0x044u320x80000000 | end, see below
0x084u32Entry count N
0x0C12 * N{u32 offset, u32 nameHash, u32 size}[]Entry table
0x0C + 12Nvar-Payloads, back to back
  • The table is sorted by nameHash, ascending, with no duplicates.
  • Payloads follow in table order, packed back to back from the end of the table, with no padding or alignment.

Name Tables

In CNK2, CNK3D and Krazy Kart Racing the archive ends after the last payload, and the word at 0x04 holds the file size with bit 31 set.

The four 2011 archives (Getaway and RT2) append the file names:

OffsetSizeTypeDescription
PE - Pchar[]Names, NUL-terminated, one per entry in table order
E4u32Byte length of the name block, E - P
E + 4var-A zlib copy of the same names (78 DA), sync-flushed and never finished

Here the word at 0x04 is 0x80000000 | E: it covers the plain names but not the length word or the compressed copy. The copy ends with the 00 00 FF FF of a sync flush and has no final block or Adler-32. Names are relative paths with forward slashes, such as data/levels/Track_Coastal_1.pxc, frontend/locale/strings.ben and shaders/blur.fp.

Name Hash

h = 0
for each byte c of the path:
    h = (h * 67 + toupper(c) - 113) mod 2^32

Recovered from the 649 stored names of the 2011 archives. It ignores case. The older archives use the same function: data/lang/lang.bin hashes to the LANG entry in CNK2, CNK3D and Krazy Kart Racing. About 45 standard hashes (CRC-32 variants, FNV, djb2, Murmur) were tried against the older archives first; none can match a custom multiplicative hash with an offset of -113.

Recovering Names

The older archives store only hashes. OmegaStudio rebuilds names by hashing candidate paths and keeping a match only when the payload fits the extension:

  1. It collects every run of three or more path characters, in ASCII or UTF-16, from every payload that is not a texture, sound, module or font, and keeps those ending in a known extension.
  2. It hashes a short list of known paths, then each collected path as written and with data/ in front.
  3. It joins each collected file stem with a built-in list of texture and audio directories, then with every directory and extension the earlier hits revealed.

In OmegaStudio

  • The archive opens when the magic is FUFS, bit 31 of the word at 0x04 is set, its low bits do not exceed the file size, and the table fits the file.
  • Every entry must lie inside the file and after the table, and no two entries may share a hash. An unsorted table is sorted on load.
  • A name table is read when the end word points past the last payload but short of the file end. Its length word must match, its last byte must be NUL and it must hold one name per entry; a name is kept only when it hashes to its entry.
  • Saving packs the payloads in table order, keeps the name block and its compressed copy as they were (rebuilding both if the table had to be sorted), and writes the end word to match.

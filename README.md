# BrewSearch Reverse Engineering Wiki

Reference for the binary file formats and in-game internals of Nintendo DS and mobile
racing games, documented from the retail archives.

Covered games:

- **Virtuos DS Racing engine** — Madagascar Kartz, DreamWorks Super Star Kartz, Hot
  Wheels: Battle Force 5, Pimp My Ride: Street Racing, Monster Jam: Path of
  Destruction. Format specs are cross-checked against the
  [OmegaStudio](https://github.com/Team-BrewSearch/OmegaStudio) reference reader.
- **Polarbit engine** — CNK2, CNK3D, Krazy Kart Racing and Ridge Racer, covering the
  PIFF model and VFS container formats. Cross-checked against OmegaStudio.
- **Suzumiya Haruhi no Chourantou / Gekitou** and **Disgaea DS**.
  - Harutou specs are cross-checked against OmegaStudio.
  - Disgaea DS pages document DSARCFL/DSEQ archive and audio formats from external
    sources (NitroStudio2, GBATEK, rustedlogic.net); some pages are reference links
    only.

For OmegaStudio-cross-checked formats, each spec page states a layout, the checks the
reader applies, and the measured round-trip result rather than an asserted layout.

File formats of the games BrewSearch takes apart, read from the game data and the games' own code. Where OmegaStudio has a plugin for a game, every layout is checked against it; the other pages name their sources.

Games

    Reading a Page

    • The opening paragraph says what the format holds and where the game uses it.
    • Layout tables follow, one per structure, in file order.
    • In OmegaStudio closes each page for a supported format: what the reader checks, what it shows and how it writes the format back.
    • Byte order, units and other rules that hold across a game are on that game's home page.

    Notation

    Numbers
    Hex with a 0x prefix, decimal otherwise. Sizes are in bytes.
    +0x10
    An offset inside the record or chunk being described
    u8, u16, u32
    Unsigned integers of 8, 16 and 32 bits
    i8, i16, i32
    Signed integers of the same widths
    f32
    IEEE-754 single-precision float
    off
    A u32 byte offset; the game's home page says where it counts from
    char[n]
    n bytes of text
    T[n]
    n values of type T, back to back
    var
    A size or position that depends on other fields
    -
    Raw bytes, padding or a field with no fixed type
    Unknown
    A field whose purpose is not known
